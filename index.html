# Hermes YouTube Uploader — App Info **Application:** Hermes YouTube Uploader **Owner/developer:** Melissa Bell (melissa.bell.sf@gmail.com) ## What this app does This is a personal, self-hosted tool that uploads ice hockey game recordings from the owner's own media library to the owner's own YouTube channel, and manages those videos' titles, descriptions, and playlists via the YouTube Data API v3. It runs on the owner's private home server. It is not distributed, has no users other than the owner, and accesses no other account's data. ## Privacy Policy The application processes no personal data other than the owner's own OAuth tokens, which are stored only on the owner's private server with restricted file permissions and never transmitted to or stored by any third party besides Google's YouTube API as required for operation. There is no analytics, no tracking, no data sharing, and no server-side storage beyond the owner's local network. Contact: melissa.bell.sf@gmail.com
